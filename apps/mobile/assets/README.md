# App assets

Use these folders for approved Mão na Roda artwork:

- `images/branding/`: logos and brand marks.
- `images/onboarding/`: welcome artwork, with optional `_light` and `_dark` variants.
- `images/illustrations/`: reusable feature illustrations.
- `fonts/`: bundled font files and their licenses.

Keep explanatory text as Flutter text, not embedded in images, so it scales and remains accessible. Use transparent PNG or WebP for artwork and register populated folders in `pubspec.yaml`.

The onboarding currently has no hero image. Do not add placeholder artwork; add approved brand assets here when available.
